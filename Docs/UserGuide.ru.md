# Как пользоваться Translation Studio

[English](UserGuide.md)

## Запуск и проекты

В готовой папке `Builds/Windows/Translation Studio` запустите `TranslationStudio.exe`. Отдельный Python не нужен; переносите всю папку вместе с `_internal`, CLI и документацией. Настройки и журналы находятся рядом с EXE в `Data`. Хранение ограничено; подробности — [StorageDiagnostics](StorageDiagnostics.md). Папка приложения должна быть доступна для записи.

Нажмите **Открыть проект / Open project** и выберите корень игры, содержащий `Translation/project.json`. Вкладки и кнопки берутся из этого файла. Если его нет, приложение покажет ожидаемый путь. Подключение игровых файлов должен подготовить агент по [IntegrationGuide](IntegrationGuide.md).

Слева находятся последние 15 проектов; при нехватке места список прокручивается. Одновременно загружен один проект. **Примеры / Examples** открывает выбор учебной папки: `Synthetic NES` содержит текст, связи, тестовые звуки, скриншот контекста и два варианта картинки; `Synthetic Sega` — текст и скриншот. Это самостоятельные примеры без ROM. Чтобы экспериментировать, скопируйте пример в доступную для записи папку и откройте копию.

**Закрыть проект / Close project** возвращает начальный экран, сохраняя запись в истории. **Убрать из списка / Remove from list** под списком удаляет выбранную запись из истории; активный проект при этом закрывается. Правой кнопкой по записи можно выбрать «Закрыть проект» или «Закрыть и убрать из списка». Файлы игры не удаляются. Несохранённые изменения требуют выбора «Сохранить», «Не сохранять» или «Отмена». Отмена оставляет и проект, и запись в списке. Во время сборки закрытие недоступно.

Без открытого проекта скрыты выбор языка перевода, состояние сохранения и проектные команды. Открытие, примеры, руководство, тема и язык интерфейса остаются доступны.

Справа в каждой строке недавнего проекта постоянно виден крестик **×**. При наведении появляется подсказка **«Закрыть и убрать из списка»**. Если проект сейчас не открыт, крестик просто убирает его запись; другой активный проект и его правки сохраняются. Повторный клик по уже открытому проекту ничего не делает и не сбрасывает редактор. Для перечитывания изменённых на диске файлов используйте **Обновить / Reload**.

## Текст

Таблица целиком доступна только для чтения; колонки разделены линиями в обеих темах. Выберите строку и редактируйте перевод в большом поле под таблицей. Оригинал всегда только для чтения. `Ctrl+C` в таблице копирует выбранную строку с разделением колонок табуляцией. Поиск учитывает ID, текст, контекст и примечания. Фильтр показывает все записи, отсутствующие переводы, изменённые записи или ошибки. Сортировка меняет только отображение. Перетаскивайте разделитель между таблицей и подробностями для изменения их высоты; нижняя область прокручивается.

Язык перевода выбирается справа сверху; язык интерфейса — слева снизу (**Русский / English**). Выбор английского интерфейса не переводит данные проекта. Правки нескольких целевых языков сохраняются вместе. Светлая и тёмная темы выбираются слева снизу. Тема и язык интерфейса запоминаются сразу, без кнопки сохранения, и восстанавливаются при следующем запуске.

При первом запуске без сохранённого или импортированного профиля интерфейс английский независимо от языка Windows. При обновлении существующий выбор сохраняется. **Руководство / User guide** открывает локальную русскую или английскую версию в зависимости от текущего языка приложения; интернет не требуется.

Колонка **Примечание / Comment** содержит общее пояснение агента. Под таблицей отдельно подписаны **Контекст / Context** (`context`, например «Главное меню») и **Примечание / Comment** (`comment`, например «Кнопка начала игры»). Их меняет агент в JSON. Пустые блоки скрыты. Поле **Моя заметка к переводу / My translation note** доступно пользователю и сохраняется в `notes` выбранного языка.

Под полем виден счётчик **Символы / Characters**, например `54 / 20`, и понятное сообщение о превышении лимита. Подсказка уточняет единицу: кодовые точки Unicode, включая пробелы, теги и переносы; составной видимый символ может занимать несколько единиц. При настройке `byteLimit` отдельно показаны байты вместе с терминатором. Нажмите **Правила перевода / Translation rules**, чтобы раскрыть все действующие правила до ввода текста. Свёрнутые правила также доступны в подсказке кнопки.

Проект может ограничивать символы, строки, байты, пустой текст, количество токенов вроде `{0}`, набор разрешённых символов и отдельно запрещённые символы, например `^~`. Регистр имеет значение; пробел, перенос и знаки токенов тоже должны входить в разрешённый набор. Автоматической замены символов или обрезки нет. Подтверждённые лимиты задаёт игровой проект отдельно для каждой записи и языка.

Ошибка показывается красным текстом под полем и состоянием «С ошибками» в таблице; фон ячейки перевода тоже отмечен. Предупреждение обозначается словом «Предупреждение» и фоном ячейки. Выделение строки может перекрыть её фон, поэтому смотрите также подробности снизу. Ошибки блокируют сохранение, предупреждения допускают его. При запрещённом символе сообщение показывает сам знак и его Unicode-код. Отсутствие лимита означает «не задан»; игровые кодировки, шрифты и упаковку всё равно проверяет адаптер игры.

**Снять перевод / Mark untranslated** устанавливает `null`. Намеренно пустая строка — другое значение: очистите нижнее поле перевода. Оно допускается только при `allowEmpty: true`. Сохранить неполный перевод можно; сборщик может требовать заполнения всех используемых записей.

## Скриншоты контекста

Если агент привязал к записи PNG, в подробностях появляются **Скриншоты контекста / Context screenshots**. Миниатюры содержат подписи; длинный список прокручивается горизонтально. Нажмите миниатюру для увеличения. Колесо меняет масштаб, перетаскивание перемещает изображение, **Вписать / Fit** показывает весь кадр. Закройте окно просмотра для возврата к переводу.

Скриншоты хранит проект; приложение не делает снимки игры и не изменяет изображения. Один файл можно использовать у нескольких записей без дублирования. Отсутствующий или повреждённый PNG отмечается предупреждением, но не блокирует независимое редактирование текста. Без вложений блок скрыт.

## Связанные фрагменты

Если проект описал связи, внизу появляется список **Связи / Relations**. Выберите реплику: слева и справа видны собранные предложения. Ниже перечислены участвующие ID; ссылки переходят к исходной записи, в том числе на другой вкладке. Полная реплика не редактируется. Измените отдельный фрагмент — связанный просмотр обновится из текущих правок.

Один ID может участвовать в нескольких репликах. Совпадение слов у разных ID не создаёт связь. Если части перевода нет, она помечается как отсутствующая, без подстановки оригинала.

## Сохранение и восстановление

**Сохранить / Save**, `Ctrl+S` записывает тексты, заметки и выбор вариантов изображений в каталоги `Translation` игры. GUI и сборщик используют эти же файлы. `Ctrl+O` открывает выбор проекта.

При переключении проекта, обновлении или закрытии с правками доступны **Сохранить / Save**, **Не сохранять / Discard**, **Отмена / Cancel**. Второй экземпляр открывает уже занятый проект только для чтения.

Если агент изменил JSON после открытия, запись останавливается с сообщением о конфликте. Через **История → Сохранить копию правок** можно немедленно обновить аварийный черновик и открыть его папку.

В игре хранятся основные JSON и два служебных снимка: `Work/TranslationStudio/Recovery/draft.json` и `previous.json`. Черновик обновляется каждые 15 секунд при правках; прежняя версия заменяется при сохранении. После успешного сохранения черновик удаляется. «Сохранить» без изменений не расходует откат. В снимки не входят медиа и сама игра.

После аварийного завершения при открытии проекта появится предложение восстановить черновик, удалить его или отменить открытие. Последние изменения до очередного интервала могут быть потеряны. Явное «Не сохранять» удаляет черновик.

**История → Вернуть предыдущее сохранение** загружает одну прошлую версию в редактор. Проверьте результат и нажмите «Сохранить». **История → Восстановить черновик** загружает черновик. **Восстановить правки…** позволяет выбрать старую копию прежней версии приложения; старые уникальные копии не удаляются без проверки.

Восстановление сверяет оригинал и ID, меняет целевые тексты, заметки и выбранные варианты изображений и не выполняет трёхстороннее слияние. Для изображений также сверяются описания ресурсов и вариантов. При изменённом оригинале или наборе вариантов нужно ручное сопоставление. PNG, WAV и игровые образы в снимки не копируются. Полные правила, поведение при сбое записи и ограничения — [StorageDiagnostics](StorageDiagnostics.md).

Запись атомарна для одного файла. При ошибке среди нескольких каталогов сообщение перечисляет уже сохранённые файлы; оставшиеся правки сохраняются в редакторе. Сборка из интерфейса не начнётся до успешного сохранения.

## Озвучка и изображения

На вкладке озвучки выберите запись и нажмите **Воспроизвести / Play** у нужного языка. Если проект настроил рассказ из частей, **Воспроизвести целиком / Play all** проиграет их последовательно с заданными паузами. Текущий ID и номер части показаны в строке состояния. **Остановить / Stop**, запуск другого звука, смена вкладки/языка/проекта отменяют очередь.

Поддерживаются WAV с целочисленным PCM 8/16/24/32 бит; 24 бита преобразуются для аудиовывода без изменения файла. Нужен работающий аудиовыход Windows с поддержкой параметров звука. Ошибка или отсутствие любого фрагмента останавливает полную сторону рассказа; части не пропускаются. В учебном проекте звучат тоны, не настоящая озвучка.

На вкладке изображений показаны PNG обеих сторон. Колесо мыши меняет масштаб, перетаскивание с зажатой кнопкой двигает изображение. **Связать вид / Link views** синхронизирует масштаб и прокрутку, **Вписать / Fit** возвращает полный вид. Отсутствующий перевод обозначается явно. Устаревший preview отмечается, если проект предоставил хеш исходного ресурса.

Если проект предоставляет несколько вариантов переведённого изображения, под просмотром видны название, комментарий, счётчик **«1 из 2»** и стрелки. Стрелки меняют только просмотр. **Использовать этот вариант / Use this variant** меняет выбор для сборки; после этого нажмите **Сохранить / Save**. Подпись «Для сборки» указывает текущий выбор редактора, а общий индикатор сообщает, сохранён ли он. Проектная сборка сначала сохраняет выбор. Внешний сборщик читает последнее сохранённое состояние.

Просмотр альтернатив не создаёт правок. Выбор отдельный для каждого целевого языка и входит в черновик и откат. При одном обычном ресурсе переключателя нет. Просмотр работает и в режиме только для чтения, выбор для сборки — только при разрешённом редактировании. Создание звуков, картинок и вариантов выполняет агент в проекте; приложение не редактирует пиксели. Варианты озвучки пока не поддерживаются. Учебный NES-сборщик копирует выбранное изображение в `Builds/Patch` и фиксирует его ID и хеш в `manifest.json`.

## Проектные кнопки

Кнопки появляются только при наличии `actions`. Например, **Пересобрать патч / Rebuild patch** сначала сохраняет правки и проверяет данные, затем запускает проектный сборщик. При первом запуске приложение показывает программы, аргументы и рабочие папки; разрешение запоминается для этой папки и списка действий. Изменение команды требует нового разрешения. Само открытие проекта ничего не запускает.

Во время команды редактор блокирует изменения и переключение проекта. Снизу видны журнал, результат и **Отмена / Cancel**, завершающая дерево дочерних процессов. В `Work/TranslationStudio/Logs` остаются журналы двух последних запусков; каждый файл ограничен 2 МиБ, при заполнении сохраняется хвост. Кнопка «Журнал сборки» слева показывает или скрывает панель. После успеха доступна кнопка **Результат сборки / Build output**. Ненулевой код, отмена и внешнее изменение входов отображаются раздельно.

Если в журнале появилось предупреждение о кодировке и последовательности вида `\xNN`, агенту нужно проверить `outputEncoding` у команды: доступны UTF-8, CP1251 и CP866. Рядом с читаемым UTF-8-журналом сохраняется `.output.bin` с исходными байтами для диагностики; он также ограничен по размеру. Это настройка вывода сборщика, а не перевода игры. Ранее созданные журналы с уже потерянными символами автоматически не восстанавливаются.

Каждая кнопка имеет фиксированный `targetLanguage` в проекте. Переключение языка правой колонки не меняет язык сборки. Смысл результата и дальнейшую установку описывает README игры.

Если не найден `python`, укажите путь к нему в **Настройки / Settings**. Это личный путь, не часть игрового конфига. В готовых учебных проектах используется свой `DemoBuilder.exe`, установка Python им не нужна.

## Что приложение не проверяет

Проектный адаптер отвечает за игровые кодировки, указатели, шрифты, размеры блоков и пригодность патча. Успех команды не означает прохождение игры в эмуляторе или на устройстве. Сведения о фактически выполненных проверках приложения находятся в [Testing](Testing.md).

## Если что-то не работает

Нажмите **Папка журналов / Open logs folder**. Отправьте `current.log`; если уже перезапустили программу после сбоя — `previous.log`. Приложение хранит только два последних журнала по 2 МиБ. Там есть технические действия и ошибки, но нет введённых переводов, заметок и нажатий клавиш. Для неполадок сборщика нужны также его журналы из папки игры. Подробности и границы диагностики — [StorageDiagnostics](StorageDiagnostics.md).
